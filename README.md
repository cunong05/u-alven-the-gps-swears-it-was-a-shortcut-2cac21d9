# The GPS Swears It Was a Shortcut

A [make.fun](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) entry for the bounty **"The GPS Swears It Was a Shortcut"** ($2 prize).

## The entry

The GPS's one-line excuse for sending the driver down the wrong road:

> In my defense, that cul-de-sac was listed as a shortcut on the map, and the map has never once apologized to me, so why should I apologize to you?

## How it works

`main.py` writes that single line to `/output/entry.txt` — one line of plain text, 146 characters, no trailing newline. It self-checks the gate (1–200 characters, single line, not only whitespace) before writing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
